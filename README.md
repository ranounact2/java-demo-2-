# java-demo-2-# ☕ Java Demo 2 - Gestion de Produits

## 📖 Description

Ce projet est une application développée en **Java** qui illustre les bases de la programmation orientée objet (POO) à travers un exemple concret de **gestion de produits**.

L’objectif principal de ce projet est de montrer comment structurer une application Java simple en manipulant des objets représentant des produits, tout en appliquant les concepts fondamentaux tels que les classes, les attributs, les méthodes et l’encapsulation.

La classe **Product** constitue l’élément central de l’application. Elle permet de représenter un produit avec ses différentes propriétés (comme le nom, le prix, ou d’autres caractéristiques), et d’effectuer des opérations de base sur ces données.

Ce projet met en pratique une approche simple et claire pour aider les débutants à comprendre comment :

* modéliser des données avec des classes
* manipuler des objets dans un programme Java
* organiser le code de manière structurée et lisible

---

## 🎯 Objectifs

* Comprendre la programmation orientée objet en Java
* Manipuler une classe métier (Product)
* Apprendre à créer et utiliser des objets
* Structurer un petit projet Java
* Développer une logique simple autour des produits

---

## 🧠 Concepts abordés

* Classes et objets
* Encapsulation
* Attributs et méthodes
* Constructeurs
* Affichage et manipulation des données

---

## ⚙️ Fonctionnement

L’application repose sur une classe principale qui crée et manipule des objets de type **Product**. Chaque produit est instancié avec ses propres caractéristiques, puis utilisé dans le programme pour démontrer les opérations de base.

## 🚀 Conclusion

Ce projet constitue une introduction pratique à la programmation Java en utilisant un cas concret (gestion de produits). Il permet aux débutants de mieux comprendre les bases avant de passer à des projets plus avancés comme les applications web ou les frameworks tels que Spring.
